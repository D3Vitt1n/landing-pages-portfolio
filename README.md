# Vitor Hugo — Soluções para seu negócio

Portfólio estático com três landing pages demonstrativas: energia solar, estética automotiva e Pilates.

Marcas fictícias. Não há clientes, depoimentos ou resultados comerciais inventados. O simulador solar é um cenário aritmético ilustrativo, não uma proposta técnica. As interações não coletam dados nem enviam mensagens.

## Publicação
GitHub Pages, branch `main`, pasta `/` (raiz). Todos os caminhos são relativos e funcionam em subdiretórios.

## Desenvolvimento
HTML, CSS e JavaScript sem dependências de build. Estes modelos demonstram apresentação visual; não utilizam ASP.NET nem SQL Server. Integrações reais podem ser implementadas de acordo com o projeto.
